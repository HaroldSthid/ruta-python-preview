La idea en una frase

Un if no es una pregunta abstracta — es una bifurcación: según sea Verdadero o Falso, el dibujo que aparece en pantalla es literalmente distinto.

10:00 – 0:40

El gancho: "¿por qué mi color nunca cambiaba?"

Alguien escribe un if para cambiar el color de una forma según una condición — pero el color queda siempre igual, pase lo que pase.

Guion de locución "¿Alguna vez escribiste un 'if' para que algo cambiara de color y no pasaba nada, nunca? El problema casi nunca es la condición — es cómo Python sabe qué parte del código pertenece a cada camino. Vamos a ver eso en cuatro minutos."
20:40 – 1:40

La revelación: if / elif / else es una bifurcación

Un diamante de decisión con dos caminos: si la condición es verdadera, un círculo amarillo; si es falsa, uno verde. Nunca los dos a la vez.

Guion de locución "Un if es un cruce de caminos. Si la condición se cumple, el programa va por un lado y dibuja algo. Si no se cumple, va por el otro y dibuja otra cosa. Nunca los dos al mismo tiempo — es uno o el otro."
No funciona
if x > 90:
fill(255,0,0)
Funciona
if x > 90:
    fill(255,0,0)
31:40 – 2:40

El truco mental: la sangría ES el camino

Python no usa llaves { } como otros lenguajes — usa la indentación (los espacios al principio de la línea) para saber qué pertenece a cada rama del if.

Guion de locución "Acá está la clave: en Python, lo que está más adentro, indentado, es lo que pertenece a esa rama del if. Sin esos espacios al principio de la línea, Python no sabe que ese fill() depende de la condición — y por eso el color nunca cambiaba."
42:40 – 3:20

Aplicado: hacia el proyecto de los cuatro cuadrantes

Combinando lo del Tema 1 (coordenadas) con esto: según en qué cuadrante caiga un punto, se elige un color distinto — exactamente lo que van a construir en el proyecto P2.A.

Guion de locución "Uniendo esto con lo que vimos del sistema de coordenadas: si combinamos condiciones sobre X y sobre Y, podemos saber en qué cuadrante del lienzo está un punto — y elegir un color distinto para cada uno. Eso es exactamente el proyecto que viene."
